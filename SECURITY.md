# Sicherheit / Security

**Sicherheitslücke gefunden?** Bitte nicht als öffentliches Issue posten, sondern vertraulich über
[„Report a vulnerability“](https://github.com/rhedv42-sudo/pc-tools/security/advisories/new) melden.
Wir antworten so schnell wie möglich und veröffentlichen eine korrigierte Version.

Unterstützt wird jeweils die neueste Version von PC-Tools (automatisches Update im Programm).

Warum Virenscanner PC-Tools manchmal fälschlich melden und wie du das prüfen kannst, steht in [SICHERHEIT.md](SICHERHEIT.md).
Datenschutz: [DATENSCHUTZ.md](DATENSCHUTZ.md).

*Please report vulnerabilities privately via "Report a vulnerability" in the Security tab, not as public issues.*
