# Mitmachen bei PC-Tools

Schön, dass du helfen möchtest! PC-Tools ist ein kostenloses Open-Source-Projekt (Apache 2.0).

## So kannst du helfen
- **Fehler melden:** [Neues Issue → „Fehler melden“](https://github.com/rhedv42-sudo/pc-tools/issues/new/choose) – mit PC-Tools- und Windows-Version und den letzten Protokollzeilen.
- **Ideen und Fragen:** in den [Diskussionen](https://github.com/rhedv42-sudo/pc-tools/discussions).
- **Übersetzungen verbessern:** direkt in PC-Tools über „Übersetzungsfehler melden“ oder per Issue „Übersetzungsfehler“. Die Sprachdateien liegen unter `lang/`.
- **Weitersagen:** Ein ★ auf GitHub hilft anderen, PC-Tools zu finden.

## Code beitragen
- Das Hauptprogramm ist `PCPflege.ps1` (Windows PowerShell 5.1 + WPF), die Android-App liegt unter `android/`, die Webseite unter `docs/`.
- Bitte kleine, nachvollziehbare Pull Requests. Neue Oberflächentexte auf Deutsch – die Übersetzung in die anderen 11 Sprachen erledigen wir.
- Jeder Push wird automatisch geprüft (Syntax unter PowerShell 5.1, Sprachdateien, Bau von EXE/Setup/Linux/Android).
- Sicherheit geht vor: keine Hintertüren, kein Umgehen von Virenschutz, keine Telemetrie, keine Passwörter im Klartext.

## Sicherheitslücken
Bitte nicht öffentlich als Issue, sondern über [„Report a vulnerability“](https://github.com/rhedv42-sudo/pc-tools/security/advisories/new) melden – siehe [SECURITY.md](SECURITY.md).

Mit deinem Beitrag stimmst du zu, dass er unter der Apache-2.0-Lizenz veröffentlicht wird. Es gilt der [Verhaltenskodex](CODE_OF_CONDUCT.md).
