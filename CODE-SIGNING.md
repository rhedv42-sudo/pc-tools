# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

Signiert werden nur Dateien, die in diesem Repository aus dem Quellcode gebaut werden
(GitHub Actions, `.github/workflows/release.yml`, `build/Build-Packages.ps1`). Jede Signatur wird einzeln freigegeben.

Alle Konten nutzen Zwei-Faktor-Anmeldung (GitHub und SignPath).

## Datenschutz

Dieses Programm überträgt keine Informationen an andere vernetzte Systeme, außer wenn der Benutzer
es ausdrücklich verlangt bzw. die Funktion selbst eingeschaltet hat. Einzelheiten: [DATENSCHUTZ.md](DATENSCHUTZ.md).
