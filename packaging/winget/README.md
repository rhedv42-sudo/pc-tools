# winget-Paket (RHEDV.PCTools)

Vorbereitete Manifest-Dateien für das offizielle winget-Verzeichnis (https://github.com/microsoft/winget-pkgs).
Einreichen: Ordner `manifests/r/RHEDV/PCTools/<Version>` per Pull Request nach microsoft/winget-pkgs (Anleitung im Start-Paket).
Prüfen unter Windows: `winget validate --manifest manifests\r\RHEDV\PCTools\14.6.2`
Neue Versionen: `wingetcreate update RHEDV.PCTools --version <neu> --urls <Setup-URL> --submit`
